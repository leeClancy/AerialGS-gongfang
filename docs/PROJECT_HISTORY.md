# 项目历史：采风 3DGS 大场景重建

这份记录说明 **高斯工坊 / AerialGS** 从哪里来：6 人摄影专业学生作业、现场怎么拍、Mac 上踩过什么坑、Windows RTX 3080 上为什么必须分块，以及本仓库已经做成了什么、还没做完什么。

原始照片、航线数据和作业模型**不进本仓库**。

## 背景与硬件

- 团队：6 人（摄影专业学生）。
- 作业：采风大场景 3D 高斯泼溅重建。采集对象为一座山、一条街，总面积大约 240 公顷。
- 主力工作站（Windows）：RTX 3080 12GB、i7-12700K、64GB RAM。
- 现场辅助（Mac，Apple Silicon）：快速验证，不作为最终训练机。
- 采集：普通相机 + 无人机。
- 最终呈现：网页查看器（如 SuperSplat），或导入 Unreal Engine 做可浏览场景。

## 拍摄策略（现场执行）

### 山体

无法环绕时，策略降级为：选取一个重要点位，只采集大约 50 米范围内的东西；采用多点画圆，以及高 / 中 / 低三层覆盖。

### 街道

放弃原地旋转。沿街蛇形走位，相机朝向行进方向斜前方约 45° 或建筑立面，靠连续移动产生视差。

### 空地协同

无人机负责宏观覆盖，地面相机多机位负责微观细节，**两者分开采集、分开训练**，不要混成一组直接训。

人员：2 人无人机（飞手 + 地勤），3–4 人地面相机分区域推进。

### 无人机参数

- 视频：4K 30fps，快门 1/2500s，ISO 250（中午大太阳）。
- 高度 50–70m，航速约 40km/h。
- 画面不能过曝（过曝会丢纹理，重建容易失败）。锁定曝光、对焦、白平衡。
- 航向重叠 ≥ 80%，旁向重叠 ≥ 70%。强光建议 ND 滤镜或收光圈。
- 40km/h 下抽帧大约 2–5 fps；可用自适应抽帧。

### 地面参数

锁定曝光、对焦、白平衡。光圈 f/8–f/11，快门 ≥ 1/125s。相邻照片重叠 ≥ 80%。地面放置明显锚点（如十字标记），供后期空地模型对齐。

## 现场预览（Mac）里踩过的坑

- **3D Splat App**（Mac）：Metal 加速，适合现场快速验证。当时用过 Medium、Image Scale 1/4、Max Splats 50 万–100 万、Iterations 15000–30000、Max SH Degree 0，以及 Single Camera、Sequential Matching、Undistort Images。导出倾向 Compressed PLY（带回 Windows）或 SPZ v2（网页 / UE）。
- **OOOSplat**（Win/Mac）：全自动流水线。Mac 上内置的是 CPU 版 COLMAP，特征提取、匹配和 Mapper 都慢。
- Mac 没有 NVIDIA CUDA。COLMAP 的 GPU 特征依赖 CUDA；增量 Mapper 和光束法平差主要吃 CPU。3D Splat App 快，是因为它绕开了这套 COLMAP 路径。

本仓库**不是** 3D Splat App 的替代品，也**没有**声称比它在 Mac 上更快。高斯工坊面向 **Windows + NVIDIA**，特征提取 / 匹配和 gsplat 训练走 GPU，GLOMAP / `global_mapper` 仍然主要走 CPU。

## Windows 3080 上的硬限制

- **64GB 内存**：COLMAP 处理大量高分辨率照片时，稠密阶段峰值可能超过 80GB。大场景必须分块，并控制缓存。
- **12GB 显存**：不能一次训练 5000+ 张的全场景。必须按区域分块训练。
- 粗时间感：8 小时内，3080 上较完整地跑完稀疏重建 + 3DGS，大约能处理 200–400 张这个量级（视分辨率和预设而定）。

软件对比里讨论过 OOOSplat、Postshot、LichtFeld Studio、Brush、DIVSHOT、GLOMAP。高斯工坊选的路线是：

**COLMAP 4.2 CUDA（特征）→ COLMAP `global_mapper` / GLOMAP 1.2（位姿）→ gsplat（训练）**，本地 HTML 控制，顺序匹配，任务队列，跑完清缓存。

## 分块、匹配、空地

- 按区域、地面、天空分组，每组大约 200–300 张。
- 同一台相机的连续序列用**顺序匹配**，不要默认穷举（计算量从平方级降到近似线性）。
- 无人机和地面视角差很大，直接混训容易梯度冲突、地面变差。应分开训练，再对齐合并。

推荐的手动大流程（作业后期仍适用）：

1. COLMAP 提特征 + 顺序匹配（`database.db`）
2. GLOMAP 或 COLMAP `global_mapper` 全局重建
3. gsplat 分块训练，输出 PLY
4. 用 LichtFeld Studio 等工具 Align / Compose 拼接（**本仓库尚未内置自动对齐合并**）
5. 网页用 `.ply` / `.splat` / `.spz`；UE 用相应插件，大场景考虑流式 LOD

## 本仓库已经做成的

高斯工坊（AerialGS）是这条路线的 Windows 本地工具：

- 只监听 `127.0.0.1`，不改源图。
- 多文件夹导入、系统选文件夹窗口、拖入、训练队列；失败跳过下一个；默认清工作缓存、保留 PLY。
- 低 / 中 / 高三档预设（同时带动训练和 COLMAP 相关参数）；分类折叠；标题旁问号悬停说明。
- COLMAP GPU 提特征 / 匹配；默认 `global_mapper`；独立 GLOMAP 作兼容入口。
- gsplat GPU 训练；假进程测试，不伪造真实训练。
- 源码 MIT。COLMAP / PyTorch / gsplat 等数 GB 二进制**不进 git**，启动后按 `packaging/versions.json` 自动下载，失败可手动导入。
